### Security and robustness

- SQL: each new statement uses `?` parameters. The path `id` is an `int`. Run 4 stored a SQL text as a plain title.
- Concurrency: `UPDATE … RETURNING` and `DELETE` are each one statement in one transaction. A `PATCH` after a `DELETE` gets 404, not 500. Run 4 saw no 500 under parallel requests. A write that waits more than the `sqlite3` default of 5 seconds gets 500. This is acceptable for one owner.
- Response data: the `Note` response model sends only the five fields of §6.3. `list[Note]` filters each list item.
